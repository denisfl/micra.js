Date picker

A keyboard-navigable month calendar built to the WAI-ARIA grid pattern: role="grid" of role="row" weeks, arrow-key roving focus, and a single tab stop. The grid is rendered from weeks() — a derived array of week objects whose cells (d0…d6) are { day, iso, empty }. Selected, "today", and roving-focus states are decided per cell by comparing its iso to state, not stored as flags.

Markup

<div class="datepicker" data-component="datepicker-demo">
  <div class="datepicker-header">
    <button @click="prevMonth">‹</button>
    <span data-text="title()"></span>
    <button @click="nextMonth">›</button>
  </div>

  <!-- One role="grid". Arrow keys via @keydown modifiers; Home/End/PageUp/
       PageDown go through onKey (Micra has no modifier for those). -->
  <div class="datepicker-grid" role="grid" data-bind="aria-label:title()"
    @keydown.up.prevent="moveUp"     @keydown.down.prevent="moveDown"
    @keydown.left.prevent="moveLeft" @keydown.right.prevent="moveRight"
    @keydown="onKey">

    <div class="datepicker-weekdays" role="row">
      <span role="columnheader" aria-label="Monday">Mo</span>
      <!-- …Tu We Th Fr Sa Su, each role="columnheader"… -->
    </div>

    <template data-each="weeks()" data-key="key">
      <div class="datepicker-week" role="row">
        <button class="datepicker-day" role="gridcell" @click="pick"
          data-text="item.d0.day"
          data-class="empty:item.d0.empty, selected:item.d0.iso === selected,
                      today:item.d0.iso === today"
          data-bind="data-iso:item.d0.iso,
                     tabindex:item.d0.iso === focus ? 0 : -1,
                     disabled:item.d0.empty,
                     aria-selected:item.d0.iso === selected ? 'true' : 'false',
                     aria-current:item.d0.iso === today ? 'date' : 'false'"></button>
        <!-- …d1 … d6 — same shape, one <button role="gridcell"> per weekday… -->
      </div>
    </template>
  </div>
</div>

Definition

Micra.define('datepicker-demo', {
  state: {
    today:    new Date().toISOString().slice(0, 10),
    selected: '',
    cursor:   '',   // 'YYYY-MM'    — the visible month
    focus:    '',   // 'YYYY-MM-DD' — the roving-focus day
  },

  onCreate() {
    this.state.cursor = this.state.today.slice(0, 7)
    this.state.focus  = this.state.today
  },

  // ── derived ──────────────────────────────────────────────
  title() {
    const [y, m] = this.state.cursor.split('-').map(Number)
    return new Date(y, m - 1, 1).toLocaleString(undefined, {
      month: 'long', year: 'numeric',
    })
  },

  // Full Monday-aligned weeks. Cells are named d0…d6 because the CSP-safe
  // evaluator has no bracket indexing — `item.days[0]` won't parse.
  weeks() {
    const [y, m] = this.state.cursor.split('-').map(Number)
    const first  = new Date(y, m - 1, 1)
    const last   = new Date(y, m, 0).getDate()
    const lead   = (first.getDay() + 6) % 7   // Monday = 0
    const cells  = []

    for (let i = 0; i < lead; i++)
      cells.push({ day: '', iso: `pad-${m}-a${i}`, empty: true })
    for (let d = 1; d <= last; d++)
      cells.push({ day: d, iso: `${y}-${this._p(m)}-${this._p(d)}`, empty: false })
    while (cells.length % 7 !== 0)
      cells.push({ day: '', iso: `pad-${m}-b${cells.length}`, empty: true })

    const rows = []
    for (let w = 0; w < cells.length; w += 7) {
      const r = cells.slice(w, w + 7)
      rows.push({ key: `${this.state.cursor}-w${w / 7}`,
        d0: r[0], d1: r[1], d2: r[2], d3: r[3], d4: r[4], d5: r[5], d6: r[6] })
    }
    return rows
  },

  // ── month navigation (header buttons) ────────────────────
  prevMonth() {
    const [y, m] = this.state.cursor.split('-').map(Number)
    this.state.cursor = m === 1 ? `${y - 1}-12` : `${y}-${this._p(m - 1)}`
    this._clampFocus()
  },
  nextMonth() {
    const [y, m] = this.state.cursor.split('-').map(Number)
    this.state.cursor = m === 12 ? `${y + 1}-01` : `${y}-${this._p(m + 1)}`
    this._clampFocus()
  },

  // ── grid keyboard ────────────────────────────────────────
  moveLeft()  { this._shift(-1) },
  moveRight() { this._shift(1)  },
  moveUp()    { this._shift(-7) },
  moveDown()  { this._shift(7)  },

  onKey(e) {                       // keys Micra has no modifier for
    const d = this._focusDate(), dow = (d.getDay() + 6) % 7
    if (e.key === 'Home')      { e.preventDefault(); d.setDate(d.getDate() - dow);       this._setFocus(d) }
    else if (e.key === 'End')  { e.preventDefault(); d.setDate(d.getDate() + (6 - dow)); this._setFocus(d) }
    else if (e.key === 'PageUp')   { e.preventDefault(); this._setFocus(this._addMonths(d, e.shiftKey ? -12 : -1)) }
    else if (e.key === 'PageDown') { e.preventDefault(); this._setFocus(this._addMonths(d, e.shiftKey ?  12 :  1)) }
  },

  // Enter / Space activate the focused <button> natively → @click="pick".
  pick(e) {
    const iso = e.currentTarget.dataset.iso
    if (!iso || iso.startsWith('pad-')) return
    this.state.selected = iso
    this.state.focus    = iso
    Micra.emit('date:picked', iso)
  },

  // ── helpers ──────────────────────────────────────────────
  _p(n)        { return String(n).padStart(2, '0') },
  _iso(d)      { return `${d.getFullYear()}-${this._p(d.getMonth() + 1)}-${this._p(d.getDate())}` },
  _focusDate() { const [y, m, d] = this.state.focus.split('-').map(Number); return new Date(y, m - 1, d) },
  _addMonths(d, n) {
    const day = d.getDate()
    d.setDate(1); d.setMonth(d.getMonth() + n)
    const dim = new Date(d.getFullYear(), d.getMonth() + 1, 0).getDate()
    d.setDate(Math.min(day, dim)); return d
  },
  _shift(days) { const d = this._focusDate(); d.setDate(d.getDate() + days); this._setFocus(d) },
  _setFocus(d) {
    this.state.focus = this._iso(d)
    const ym = this.state.focus.slice(0, 7)
    if (ym !== this.state.cursor) this.state.cursor = ym
    this._focusActive()
  },
  _clampFocus() {            // keep the focus day inside the visible month
    const [cy, cm] = this.state.cursor.split('-').map(Number)
    const day = Number(this.state.focus.slice(8, 10))
    const dim = new Date(cy, cm, 0).getDate()
    this.state.focus = `${cy}-${this._p(cm)}-${this._p(Math.min(day, dim))}`
  },
  _focusActive() {           // grid re-renders next microtask — then focus
    setTimeout(() => {
      const el = this.$el.querySelector(`[data-iso="${this.state.focus}"]`)
      if (el) el.focus()
    }, 0)
  },
})

Integration

  • ARIA grid pattern. The calendar is a role="grid" labelled by title(); the weekday header is a role="row" of role="columnheader" cells, and each weeks() entry renders a role="row" of seven role="gridcell" day buttons.
  • Roving tabindex + keyboard. A focus state field (a 'YYYY-MM-DD' day) is the single tab stop — only the cell whose iso === focus gets tabindex="0", the rest -1. Arrows move a day/week (via @keydown.left/right/up/down.prevent), Home/End jump to week edges, and PageUp/PageDown change month (Shift for year) through onKey — the keys Micra has no modifier for. After each move, focus is sent to the new cell on the next tick (the grid re-renders first). Enter/Space activate the focused <button> natively.
  • String-valued ARIA. data-bind renders a JS boolean as attribute presence, so every ARIA state binds a string expression: aria-selected:item.d0.iso === selected ? 'true' : 'false' and aria-current:item.d0.iso === today ? 'date' : 'false', never a bare boolean.
  • Cursor is a string ('YYYY-MM') — survives JSON round-trips, easy to compare, and reading it never produces a stale Date object. It always tracks the focus day's month, so the visible grid is guaranteed to contain the tab stop.
  • Padding cells for the Monday-aligned grid (lead and trailing, so every row is a full seven) carry empty: true and a synthetic iso like pad-3-a0 — they render as disabled, visually-hidden buttons that drop out of the accessibility tree.
  • Selected / today / focus state are computed by comparing each cell's iso to state.selected / state.today / state.focus inside data-class and data-bind — never written back to the day object.
  • Locale-aware title. toLocaleString({ month, year }) respects the browser's locale. Set document.documentElement.lang to force a specific one.
  • Bus handoff. 'date:picked' publishes the ISO string so a form, a chart, or a fetch can react.

Pitfalls

  • Don't store the visible month as a Date object — its identity changes on every mutation and you risk timezone drift across toLocale* calls. Strings are stable.
  • Don't precompute weeks into state. Cursor/focus changes already trigger a re-render; the method runs on read.
  • Don't key the weeks on $index — month-to-month transitions reorder rows and you'd lose keyed-diff benefits. Key on a value that ties the row to its month (here cursor + week index).
  • Don't bind a bare boolean to aria-selected / aria-current: data-bind would emit attribute presence (aria-selected="") or remove it, not the literal "true"/"false" a screen reader needs. Always bind the string ternary.
  • Don't .focus() the new cell synchronously inside a key handler — its tabindex still reflects the old focus until Micra's batched re-render runs. Defer with setTimeout(…, 0).
